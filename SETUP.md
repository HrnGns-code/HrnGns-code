# Harun Güneş / HrnLabs GitHub profile package

1. Use a public profile repository named `HrnGns-code`, matching your GitHub username.
2. The README profile link and banner are already configured for `HrnGns-code`.
3. Extract the ZIP, then upload `README.md`, `assets/`, `scripts/` and `.github/` to the repository root. Preserve the folder structure.
4. If the upload screen rejects `.github`, choose Add file → Create new file. Enter `.github/workflows/profile-visuals.yml`, paste the workflow contents from the package or README, and commit.
5. Under Settings → Actions → General → Workflow permissions, enable Read and write permissions.
6. Open Actions → Refresh profile visuals → Run workflow to start the first update.

The banner, typing animation and badges appear immediately. Statistics and snake placeholders are replaced with real data after the first successful Actions run. Daily updates are scheduled for 03:23 UTC.

Metrics include owned public repositories (including forks), owned public non-fork repositories, total stars on those non-fork repositories, and followers. Private repositories and organization-owned repositories are excluded. If the GitHub API fails, the script stops rather than writing false zero values.

The README includes the complete workflow and setup notes in a collapsible section. You can remove that section once setup is complete. This SETUP.md file does not need to be uploaded to the profile repository.

Project descriptions and release dates are based on the information you provided. No repository, store, website or social links have been invented. The founder vision does not imply legal company registration.

The design uses custom SVGs with no JavaScript or external fonts. Motion is implemented within SVGs; the README does not depend on custom CSS or scripts. Local previews may differ from GitHub's exact rendering.
